# Правила проекта «Цех»

## Запуск тестов

По указанию пользователя от 06.11.2026 тесты запускаются только по его явной просьбе. Не запускать автоматически unit, UI, instrumentation, E2E, `test`, `connectedDebugAndroidTest` или `scripts/verify.sh`. Просьба изменить код или собрать APK сама по себе не разрешает запуск тестов.

При запросе APK для установки использовать `./scripts/build-debug-apk.sh`: только assembleDebug с `-Pandroid.injected.testOnly=false` и проверка пакета/подписи, без тестовых задач. Не выдавать IDE-артефакт с testOnly=true. В отчёте честно указывать, какие проверки были фактически выполнены.

## Git

По указанию пользователя от 06.11.2026 не выполнять операции Git по собственной инициативе. Коммиты и отправка кода — только по явной просьбе пользователя. Запрос изменить приложение или собрать APK не разрешает коммит, push и другие операции Git. Текущие изменения оставлять в рабочей директории.
