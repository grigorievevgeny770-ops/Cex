# Чертежи и расход по площади v1.1

Надстройка над PRODUCTION_REQUESTS.md. Backend находится в sklad, в Android он не копируется. APK: versionCode 2, versionName 0.2.0.

Сервер возвращает drawing_version для позиции. Android читает GET /api/workshop/v2/requests/{request_id}/lines/{line_id}/drawing: schema_version=1, version, blank_width_mm и drawing с length_mm, segments(start_mm/end_mm), angles_deg, turns, edge1/edge2. Размеры Long, углы BigDecimal. Неизвестная схема, неправильные идентификаторы, размеры, углы, края или несовпавшая версия дают ошибку; выпуск блокируется до загрузки всех актуальных чертежей.

Работник видит профиль, для косого изделия оба сечения, размеры начала/конца, длину, углы и направление сгибов, два края и расчётную ширину. color и thickness_mm показываются независимо от флагов клиентской печати. Редактора и менеджерских команд в Android нет.

При allowed_actions=manufacture_area доступна кнопка «Изготовлено · расход по чертежам» с подтверждением. POST /api/workshop/v2/requests/{id}/manufacture-area передаёт только expected_version и client_token. Площадь считает сервер. Android не отправляет локальный результат Canvas или собственное списание. Старый manufacture для старых заявок остаётся без изменений.

За подгиб/фальц сервер добавляет 10 мм один раз на каждый свободный край. Для косого изделия ширина=max(сумма начала,сумма конца)+края. Пример 150/130+80/100: 230 мм до краёв. Площадь=ширина×длина×физическое количество/1000000, итог округляется сервером до 0,0001 м². Без существующего перевода базовой единицы в штуки сервер отклоняет выпуск.

Команда использует защищённый Room-журнал, scope=request, сохранённые байты и токен. Потерянный ответ не вызывает автоматический replay. После перезапуска пользователь явно повторяет сохранённую команду. Новое нажатие не создаёт второй запрос, пока исход прежнего не установлен. Сессия, cookie и Android Keystore не ослаблялись.

Проверки: MockWebServer для точного контракта и неизвестной схемы; Room/Robolectric для восстановления команды; ViewModel для блокировки при недоступном/устаревшем чертеже и двойного нажатия. Результаты фиксируются после прогона; эти тесты не заменяют проверку на устройстве.

Сборка: JDK 25 для Gradle, JDK 17 для toolchain, SDK 36. `./gradlew test lint assembleDebug -Pandroid.injected.testOnly=false --no-configuration-cache`; для APK без тестов `./scripts/build-debug-apk.sh`. Debug-prefill пароли должны быть пустыми. Проверить aapt/apksigner, package/version/testOnly и SHA256. Эмулятор и Android отсутствуют; connectedDebugAndroidTest не запускался.

До TEST нужны серверные Linux-проверки и ручная проверка читаемости на общем планшете, потери ответа/перезапуска и цикла с отменами. Перенос новой версии — после отдельного разрешения; PROD не затрагивается.
